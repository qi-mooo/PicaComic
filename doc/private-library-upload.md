# 上传下载漫画到私人漫画库

需要私人漫画库服务端 `1.3.2` 或以上，以及包含本功能的 PicaComic 客户端。

1. 在漫画源管理中导入服务端的 `/source.js`，其 key 为 `private_nas_library`。
2. 在账号管理中登录“私人漫画库”的管理员账号。
3. 在下载列表中选择漫画，打开“更多”，点击与 ZIP、PDF 导出并列的“上传到私人漫画库”。Fluent 界面在工具栏中提供该按钮。

App 使用漫画源地址和已保存的登录会话。登录过期时尝试重新登录；没有上传权限时提示使用管理员账号。

每部漫画分别打包和上传，仅包含已下载的图片与封面。章节保持本地顺序，未下载的章节不会补下载。上传完成后立即在服务端入库，并清理临时 ZIP；本地原漫画保留。

重名漫画跳过，某部打包或上传失败后继续处理后续漫画。完成时显示成功、跳过、失败和未完成数量，以及失败详情。打包期间取消会在当前打包结束后停止；上传期间可以中止请求。取消时服务端可能已保存当前漫画，重试会跳过重名项。

默认限制为单部 ZIP 2 GB、50,000 个图片条目及解压后图片 20 GB。超出限制的漫画会报告失败。

## 接口

App 先请求 `GET /api/auth/me` 检查 `admin: true`，然后逐本请求 `POST /api/uploads`。两者使用漫画源的 `Authorization: Bearer <token>`，不使用网页登录 Cookie。

上传请求为 multipart，字段 `files` 是当前漫画 ZIP，`titles` 是漫画名。服务端 `files: 1` 和一项 `uploads` 表示成功；`files: 0` 和一项 `skipped` 表示重名跳过。401 会尝试重新登录一次并重新创建上传流；403 和旧服务端的 404 会停止队列并提示原因。
